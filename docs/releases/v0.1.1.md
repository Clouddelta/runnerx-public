# v0.1.1 - English-only project content

This update standardizes the RunnerX repository on English while retaining the Docker Compose delivery model from [v0.1.0](v0.1.0.md).

## Changes

- English documentation, code comments, docstrings, messages, examples and synthetic sample content.
- Canonical English spreadsheet headers, with supported English aliases and time-unit formats documented in the [data contracts](../data-contracts.md).
- Regenerated sample workbooks and updated parser fixtures.
- An English-language contribution convention for future changes.

## Compatibility

Localized import headers, gender values and time-unit strings accepted by v0.1.0 must be converted to the canonical English field names and supported values before importing with v0.1.1. Use M/F/O/U for gender, numeric seconds or MM:SS/HH:MM:SS for race times, and numeric seconds per kilometre or MM:SS for pace. The [sample files](../../data/sample/README.md) provide the current input format.

No schema migration is needed for this update. Previously stored application data is unchanged. The regenerated sample XLSX files have new SHA-256 fingerprints, so the first demo seed after upgrading processes the new registration workbook as an update. Existing runner and registration IDs are preserved through their business keys. The training CSV is unchanged and remains eligible for the existing duplicate-import skip.

## Verification

The local suite passed 156 tests with one Windows symlink-permission skip. All 11 real Docker business checks passed with successful QA cleanup. A repository audit found no Chinese text in the 60 project files, including decoded Python strings and workbook XML metadata. The regenerated demo retained its 30 runners, 30 registrations, 360 sessions and existing record identities. See the [validation record](../validation.md) for execution details.

## Run and upgrade

Follow the [Docker guide](../docker-guide.md) for startup, authentication, imports and upgrades. The repository remains private, and the release requires no cloud deployment.
